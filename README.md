# 🧬 Game of Life

A terminal-based implementation of Conway's Game of Life, built in Python as a 3rd-year introduction to programming project.

## What is the Game of Life?

Conway's Game of Life is a cellular automaton devised by mathematician John Horton Conway in 1970. It simulates the evolution of a grid of cells across generations based on simple rules:

- A **live cell** with 2 or 3 neighbors **survives**
- A **dead cell** with exactly 3 neighbors **becomes alive**
- All other live cells **die**, all other dead cells **stay dead**

From these 4 rules, complex patterns emerge — making it a classic introduction to algorithmic thinking.

## Features

- Runs directly in the terminal — no dependencies, no install
- Grid evolves generation by generation
- Configurable grid size and initial state

## Context

3rd year school project — introduction to Python programming.
